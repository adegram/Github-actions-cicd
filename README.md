# GitHub Actions CI/CD

A collection of GitHub Actions workflows built to automate different parts of the software development and delivery process.

The projects explore CI/CD automation using GitHub Actions, from basic continuous integration workflows to testing, container builds, security checks, infrastructure automation, and deployments.

## What You'll Find Here

The projects cover different areas of GitHub Actions and CI/CD automation, including:

- Continuous Integration
- Automated testing
- Node.js CI
- Docker image builds
- Docker registry integration
- Code quality checks
- Kubernetes deployments
- Terraform automation
- Terraform plan and apply workflows
- GitOps workflows

Projects may vary in scope and are organized separately based on the CI/CD workflow being demonstrated.

## Technologies

- GitHub Actions
- GitHub
- Docker
- Docker Hub
- Node.js
- npm
- Terraform
- Kubernetes

Additional tools may be used where they are relevant to individual workflows.
